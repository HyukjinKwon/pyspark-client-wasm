# API reference

The public surface of `pyspark_connect_web` is intentionally tiny: you `install()`
the patch once, then use ordinary PySpark. Everything else
(DataFrame, Column, functions, `SparkSession`) is upstream PySpark and documented
by the [PySpark project](https://spark.apache.org/docs/latest/api/python/).

```python
import pyspark_connect_web as pcw
pcw.install()
```

## Patch internals

The functions below live in `pyspark_connect_web.patch` and are re-exported from
the top-level package. `set_stub_factory` / `set_channel_factory` are the
pluggable hooks used to inject the lane-1 transport stub and the lane-3
`SyncChannel` (and to inject fakes in tests).
